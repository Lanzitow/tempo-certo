# Tempo Certo

Site da N2: cadastro, login, consulta de clima (API Open-Meteo), banco SQLite e relatório para impressão.

## Rodar local
```
python -m venv .venv
.venv\Scripts\activate      # no Linux/Mac: source .venv/bin/activate
pip install -r requirements.txt
python app.py
```
Acesse http://127.0.0.1:5000

## Tecnologias
Python, Flask, SQLite, HTML, CSS e JavaScript.
